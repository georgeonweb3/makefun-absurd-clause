One absurd clause (178 characters) buried deep in a terms-of-service agreement:

> Clause 11.8: the user’s dreams remain the user’s property, except those dreamed between 2 a.m. and 4 a.m., which are licensed to the company in perpetuity, including any sequels.

The line is the whole entry. `main.py` prints it, validates the 1–200 character gate, and writes it to `entry.txt` in the output dir (`MAKEFUN_OUTPUT_DIR`, `/output`, or a temp dir — never inside the repo, which the grader mounts read-only).

## Run it

```sh
python3 main.py
```
